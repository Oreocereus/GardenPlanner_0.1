An interactive Python GUI application that helps users choose the perfect tree for their garden based on size, seasonal interest, and decorative features. Built with `tkinter`, this tool walks users through a fun and visual selection process — no gardening experience needed!

Features

- Select tree size: Small, Medium, or Large
- Filter by seasonal interest: Spring, Summer, Autumn, or Winter
- Choose decorative qualities like:
  - Pretty Flowers
  - Edible Fruit
  - Interesting Bark
  - Evergreen or Deciduous
- See a photo and description of the recommended tree at the end

---

Installation

1. Clone this repository

2. Navigate to project folder

3. Run application
